# AIMS Audit Plan — Template

> Original template. A risk-based plan for a Stage 1 / Stage 2 / surveillance /
> recertification audit of an ISO/IEC 42001 AIMS. Sampling is justified across the
> **AI lifecycle**, weighted to higher-risk AI systems.

| Field | Value |
|---|---|
| Audit ID | |
| Audit type | Stage 1 / Stage 2 / Surveillance / Recertification / Internal |
| Criteria | ISO/IEC 42001 + SoA + applicable legal/regulatory (e.g., EU AI Act) |
| Scope | AI systems, lifecycle stages, sites, teams, and boundaries in scope |
| Role(s) | Provider / user / both — per system where they differ |
| Objectives | What this audit must determine |
| Audit team | Lead auditor + members (note competence, AI/ML literacy & impartiality) |
| Dates & method | On-site / remote (ICT) / hybrid |
| Sampling approach | Risk-based across the AI lifecycle; weight high-risk systems and shadow-AI checks |
